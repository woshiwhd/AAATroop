# 资源后端路由规则

## 路由输入

路由由 `AssetRoutingConfig` 决定：

- `defaultBackend`
- `prefixRoutes`（按 key 前缀路由）
- `groupRoutes`（按 groupKey 路由）

实现位置：`Assets/Script/Core/Assets/Runtime/BackendResolver.cs`

## 路由优先级

### 资源 key 路由

1. 命中 `prefixRoutes` 的首个前缀
2. 否则使用 `defaultBackend`

### 资源组路由

1. 命中 `groupRoutes` 的精确 `groupKey`
2. 否则使用 `defaultBackend`

## 组加载规则

`LoadTextAssetsByGroupAsync(groupKey)` 的执行逻辑：

1. 若 `AssetGroupsConfig` 中有该组且含显式 `assetKeys`，逐 key 加载（推荐，后端无关）。
2. 否则走后端自己的 group 加载能力（`ResourcesBackend` 支持 `Resources.LoadAll<TextAsset>(groupKey)`）。

## 回退规则

在 `AssetService.LoadAssetAsync` 中：

- 若目标后端不可用，会尝试回退到 `ResourcesBackend`（若可用）。
- 加载失败按 `AssetPolicies` 执行重试。

## 命名建议（配合路由）

- `base_`：首包基础资源
- `feature_`：玩法模块资源
- `event_`：活动资源
- `audio_`：音频资源

可配前缀示例：

- `base_` -> Resources
- `feature_` -> YooAsset
- `event_` -> YooAsset
- `audio_` -> YooAsset
